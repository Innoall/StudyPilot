# Annotated Agent Transcripts

Before submission, add one complete raw coding-agent transcript per team member as `<student-id>-<student-name>.md`. Mark every human interruption, approval, rejection, or redirection and explain why it was necessary. Collectively cover requirements classification, candidate architecture evaluation, plan approval before code, implementation, verification compliance, and architecture revision from test evidence.

Never include passwords, access tokens, API keys, `.env` contents, or real student records in a transcript.
