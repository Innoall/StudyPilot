# Debt Register

Updated for the project-only scope on 2026-11-16 (Asia/Hong_Kong), ADR-002 and source under `src/`. Role names below identify the required responsibility, not an invented team assignment. Report, personal reflections and contribution allocation are deferred by user instruction.

## Resolved implementation gaps with local evidence

- **Guardrail debt:** the former permissive AI JSON merge is replaced by strict bounded summary/three-suggestion parsing, extra-authority rejection, valid task-reference bounds and deterministic plan preservation. Provider and fixed-evaluation negative cases now exercise these boundaries.
- **Evaluation debt:** the former CI TODO/forced failure is replaced by a fixed synthetic response/privacy/authority evaluation that calls the actual implementation. This resolves missing offline execution, not real-model usefulness evidence.
- **Hidden dependency:** the AI adapter now has explicit CityU CSLab/OpenAI/DeepSeek destinations and Chat Completions contracts. Personal key failure cannot consume shared quota. A supported protocol does not guarantee current provider access or every model's parameter compatibility.
- **Temporal guardrail debt:** Hong Kong calendar arithmetic, current-time cutoff, exact deadlines, merged availability, breaks and remaining effort have frozen positive/negative regression coverage. Performance evidence is a local benchmark, not production monitoring.
- **Schema debt:** requirements checks now read the actual JSON Schema and enforce a documented strict subset. Unsupported keywords fail closed. Full YAML syntax and complete JSON Schema draft compliance are not claimed.

## Open debt and exit criteria

- **Prompt rot — owner role: AI maintainer.** Runtime constraints live in `src/lib/ai.ts`; the prompt-consistency test now checks the active text/version against `prompts/prompt_v1.1.yaml`. Continue review on every prompt/model change. Exit for a selected release: consistency and fixed evaluations pass, actual selected-model evidence is recorded and a human reviews advice quality. Text consistency alone does not prevent usefulness degradation.
- **Evaluation debt — owner role: verifier.** Synthetic cases prove adapter and authority boundaries, not actual model relevance. Exit: protected live normal/injection runs on the release commit, approved provider/model metadata, thresholds met and a recorded usefulness review. Default live skips are explicitly not completion.
- **Guardrail debt — owner role: security/integration maintainer.** Canvas personal tokens are controlled self-testing, not approved multi-user authentication. Exit: university-approved scoped OAuth, reviewed authenticated session/token storage, refresh/revocation/deletion tests and real end-to-end evidence. Keep production personal-token testing disabled unless a controlled test is explicitly authorized.
- **Operational debt — owner role: repository maintainer.** Local CI files do not enable branch protection, test-review bootstrap, independent approval or the protected live-evaluation environment. Exit: remote required checks/rules and reviewers verified, initial governance adoption reviewed, trusted-base verifier installed and real approvals recorded. The current interactive user approval is not a fictional GitHub review.
- **Hidden dependency — owner role: deployment maintainer.** Server AI mode can spend operator quota and deployment/proxy logging may capture request bodies outside app code. Exit before public shared deployment: authenticated access, rate/quota limits, body-log redaction, HTTPS and credential-handling review. Personal mode remains separate and never silently falls back to this quota.
- **Hallucinated dependencies — owner role: builder/reviewer.** No package was added for this slice. The lock/registry/integrity checks do not replace ongoing vulnerability review or upstream compatibility assessment. Exit for future additions: documented need, reviewed version/source, lock update and independent review before use.
- **Untouchable code — owner role: application maintainer.** The baseline remains extendable but the main workspace still contains several interaction flows. Exit trigger: a later feature makes independent UI testing or safe edits difficult; then refactor into bounded components under an ADR and preserve existing acceptance coverage. Do not add abstractions solely for speculative scale.
- **Agent-induced bloat — owner role: reviewer.** Keep new source, tests and governance proportionate to the manual/AI/import scope. Exit/checkpoint each change: remove unused additions and avoid cloud accounts, persistent keys or unrelated features without explicit requirements.
- **Human/cognitive debt — owner role: human supervisor.** Real independent reviews, browser acceptance evidence, original annotated sessions and eventual course submission material require human records. Exit: record the actual interventions/review and fill deferred materials when that scope resumes; never generate stand-in approvals, identities, contributions or transcripts.
- **Data lifecycle debt — owner role: product/security maintainer.** Local workspaces have user-managed retention and no cross-device recovery. Exit if cloud storage or automatic retention becomes a requirement: define authenticated ownership, migration/retention/deletion policy, backups and privacy tests in a new ADR. Existing local backups do not satisfy a cloud recovery promise.

## Release assessment boundary

Type checks, offline suites, fixed evaluation and local build are executable evidence. Actual local browser results are recorded in `docs/validation-evidence.md`, including the distinction between the real local rule API and synthetic intercepted Canvas responses. Live provider availability, school approval and GitHub protection remain external evidence. The project is not declared merge-ready or fully coursework-submission-ready by this register.
