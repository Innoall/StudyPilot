# Human-only Always-on Rules

- Stop before code generation until the human approves a traceable execution plan.
- Never request or expose CityUHK passwords, API keys, OAuth tokens, or real student records.
- Never give the LLM authority over deadlines, task identity, credentials, or schedule validity.
- Stop for human approval before changing safety-critical paths or architecture.
- Update tests, traceability, review records, and AI-use log in the same change.
